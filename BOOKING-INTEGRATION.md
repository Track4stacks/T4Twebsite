# Booking and subscription integration

The branded `/booking/` flow replaces the former Setmore homepage embed. It is currently a clearly labeled design preview with example availability, no data submission, no appointment creation, and no charges.

Recurring memberships use **Shopify subscription checkout**, with Biweekly (every other week), Weekly, and Twice a week visit choices. Square is not the membership checkout path. Live scheduling needs a secure backend; Setmore API access is still needed if Setmore remains the scheduling provider.

See [the Shopify setup and activation guide](shopify/README.md) for authoritative installation instructions, billing assumptions, integration requirements, and verification status. Never commit API tokens or payment credentials.
